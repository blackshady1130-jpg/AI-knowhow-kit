MY LENS

我持续追问的三个问题

单个模型分数、一次 demo 或 token 用量都不足以解释真实价值。我的笔记围绕下面三个控制点展开。

01 / CAPABILITY

能力如何形成？

模型变强来自数据、训练、推理预算，还是 Harness 与环境？哪些提升能迁移到真实任务？

02 / VERIFICATION

结果如何验证？

谁定义成功、谁设计 verifier、谁处理环境噪声，最后谁愿意为结果买单？

03 / LEARNING

经验如何回流？

badcase、人工修正和客户反馈，能否变成下一轮可测的 Skill、Eval、数据或产品改进？

RESEARCH ARC

从模型能力到真实结果

七篇文章不是七座孤岛。它们共同回答一条链路：能力怎样被系统接住、被验证、进入工作流，再接受商业和社会结果的检验。

CASE / AI CODING

AI Coding 是这条链路目前反馈最密集的验证场：任务可执行、结果可测试、过程可追踪、错误可回滚。它提供方法，但不能直接代表所有知识工作。
