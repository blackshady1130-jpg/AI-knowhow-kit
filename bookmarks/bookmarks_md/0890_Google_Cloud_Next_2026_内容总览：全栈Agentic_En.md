一、大会核心定调：三大核心优势，筑牢智能体时代企业转型底座

过去一年，谷歌云始终聚焦于交付驱动企业业务增长的创新成果，在全产品矩阵中推出了数千项全新能力：第七代Ironwood TPUs与全新Axion定制处理器已全面可用，为Agentic Enterprise提供专用、高性价比的基础设施；推出了Gemini 3.1 Pro与全新图像生成模型Nano Banana 2等里程碑式基础模型；发布Gemini Enterprise，将谷歌顶尖的AI能力带给企业每一位员工。

如今，全球企业选择Google Cloud，核心源于三大不可替代的优势：

1. 全集成AI技术栈：覆盖AI基础设施、Gemini等领先模型、数据管理能力、企业级底座、开发者工具与平台，以及智能体与应用的全栈方案，为企业创新提供完整的核心架构，而非碎片化的独立服务。


2. 安全设计原生、企业级就绪的底座：基于Zero Trust安全架构、具备全球级可靠性的安全统一平台，同时支撑着谷歌对性能要求最严苛的全球级服务，不仅默认具备安全能力，还提供领先的情报驱动、AI赋能的网络安全解决方案。


3. Gemini Enterprise：面向每一位员工与客户的AI入口：让企业全员都能构建、使用、部署和管理前沿AI智能体，覆盖客户体验优化、供应链效率提升、营销内容创作等全业务场景，彻底改变企业的工作方式。


二、核心重磅发布：Gemini Enterprise Agent Platform，智能体时代的端到端操作系统

本次大会最核心的发布，是全新的Gemini Enterprise Agent Platform——一款用于构建、扩展、治理和优化智能体的全栈平台。该平台基于谷歌领先的基础设施构建，与数据和安全能力深度融合，是Agentic Enterprise的核心底座。它整合了Vertex AI的核心优势与颠覆性全新功能，同时包含面向全员的Gemini Enterprise app，实现了智能体全生命周期的统一管理。


![](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_jpg%2F3zTGBoZibFLFhTud6Jndx6HrYibzXaC4nyuSKW9CU8iawwCCY3vzT3WWvseaRrZ9gd99dADQEq9htnVwInSB51KdsnYStl0rg3BBhHtmv1RQbQ%2F640%3Fwx_fmt%3Djpeg)


目前，Gemini Enterprise已迎来强劲的增长势头，2026年第一季度付费月活用户环比增长40%。平台为开发者与企业用户提供了全球领先模型的顶级访问权限，包括：Gemini 3.1 Pro（针对复杂工作流编排优化的旗舰模型）、Gemini 3.1 Flash Image（又名Nano Banana 2，高保真UI与视觉资产生成模型）、Lyria 3（专业级音频与音乐生成模型），以及Anthropic旗下Claude Opus、Sonnet、Haiku全系列模型，本次大会还新增了对Anthropic Claude Opus 4.7的支持。

整个平台围绕构建、扩展、治理、优化四大核心支柱设计，推出了全维度的创新功能，实现了团队间的无缝协作：

（一）快速便捷地构建智能体，赋能全员规模化创新

- Agent Developer Kit (ADK)：新增基于图谱的框架，可定义智能体协同解决复杂问题的清晰、可靠逻辑；


- Agent Studio：全新低代码界面，让每位开发者都能通过自然语言构建、测试和发布智能体；
- Agent Registry：提供统一控制点，对企业内部所有智能体与工具进行索引，确保其可被发现与合规治理；


- 生态集成与Agent Marketplace：可直接从Gemini Enterprise中即时部署Atlassian、Box、Lovable、Oracle、ServiceNow、Workday等合作伙伴的专用智能体，同时支持合作伙伴智能体通过统一Agent Registry，实现可复用技能与托管环境的深度集成；


- Model Context Protocol (MCP) 全面兼容：支持将Agent Platform连接至任意MCP Server，同时将Google Cloud服务以MCP形式开放，实现任意智能体与Google Cloud的无缝交互。

（二）规模化扩展与编排智能体，打通从概念验证到生产落地的全路径

- Agent-to-Agent Orchestration：支持智能体之间无缝委派任务，覆盖复杂、生成式与确定性编排模式，确保合规等关键流程始终遵循指定路径执行；


- 运行时全面升级：通过重构底座实现亚秒级“冷启动”，数秒内即可完成新智能体部署，同时大幅降低闲置基础设施开销；


- 长运行智能体支持：让智能体能够持续进行自主推理，管理多步骤复杂业务工作流；


- 安全沙箱：提供隔离环境，让智能体可执行模型生成的代码，完成基于浏览器的自动化等计算机操作任务，且不会对主机系统造成风险；


- Memory Bank与Memory Profiles：为智能体提供可扩展的长期记忆能力，用持久化上下文替代临时会话，可在数月内回溯特定用户细节与项目历史，交付高度个性化的交互体验；


- Agent Sessions：通过唯一标识符实现跨异构企业系统的精准会话追踪，大幅提升开发者灵活性。


（三）企业级智能体治理，以同等严谨度管控智能体与核心业务系统

- Agent Identity：为每个智能体分配唯一的加密ID与定义清晰的授权策略，所有策略均可追溯与审计，确保智能体受企业策略管控，仅在分配任务范围内运行，复杂场景可向人工发起求助；


- Agent Gateway：企业智能体生态的“空中交通管制中心”，可识别MCP、A2A等智能体协议，提供集中化、实时的策略执行能力，从设计层面确保智能体与数据的每一次交互都安全、合规且可扩展；与Model Armor集成的内嵌防护能力，可抵御提示词注入、工具投毒与敏感数据泄露威胁；


- Agent Anomaly Detection：在异常行为影响业务之前主动标记可疑操作，通过分析智能体行为背后的意图，自动检测工具滥用、未授权数据访问、推理漂移等风险；


- Agent Security dashboard：通过Security Command Center提供AI风险与合规状况的全局视图，支持团队映射智能体与模型的关联关系，自动化资产发现，扫描底层操作系统与语言包中的漏洞。

（四）数据驱动的智能体优化，精准把控性能、成本与效果

- Agent Observability：提供交钥匙式仪表盘，具备自动化日志与智能体审计能力，通过标准化、兼容OTel的遥测数据，实现全链路核验、执行路径可视化、推理循环快速诊断与性能指标实时监控；


- Agent Simulation：在受控环境中通过类人的合成交互，对智能体进行规模化压力测试，生成数千组合成的多步骤客户交互，严格评估智能体的逻辑与对话流程；


- Agent Evaluation：通过多轮自动评分器，基于实时生产流量持续为智能体表现打分，实时检测质量下降与异常情况。

与此同时，Gemini Enterprise app推出了多项全新能力，让企业全员可在单一环境中发现、创建、共享和运行AI智能体：

- Agent Designer：沿用Agent Platform的无代码设计体验，让员工可借助任意企业连接器，构建基于日程或触发器的复杂智能体，提供虚拟流程图，支持对工作流的检查、测试与审批，确保关键业务流程全透明；

- Canvas：内置交互式编辑器，团队可在同一界面中创建和编辑Docs与Slides，支持导出为Microsoft 365文件；


- Agent Gallery：可访问Adobe、Atlassian、Lovable、ServiceNow等合作伙伴的第三方智能体，新增Asana、Mailchimp、Workday等更多第三方连接器，实现智能体与企业核心业务系统的深度打通。

三、算力革命：第八代TPU双芯重磅亮相，AI Hypercomputer全栈升级

本次大会，谷歌云发布了AI基础设施的里程碑式创新——第八代TPU系列芯片，同时完成了AI Hypercomputer的全栈升级，为Agentic Enterprise打造了极致性能、高性价比的算力底座。

专为高要求AI工作负载设计的AI Hypercomputer，是一套先进的专用架构，它将面向性能优化的计算、存储、网络硬件，开源软件与ML框架，以及灵活的消费模式，整合为单一集成系统，通过全组件协同演进，为客户带来行业领先的能效与性能表现。其核心拥有行业最丰富的计算选项矩阵，覆盖谷歌自研TPUs、Axion CPUs，到最新的NVIDIA GPUs，为企业提供极致的架构选择灵活性。


![](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_jpg%2F3zTGBoZibFLHFicxPJGayqT1Pwib8vic6EdQ0WJRFWuMt1XZd7FV8SgS5uImjR99RJYu9HntuMESMtZ7GNvO9GKBlHdFnh7GkQeX6q8MEgMNRAc%2F640%3Fwx_fmt%3Djpeg)


本次大会发布的AI Hypercomputer全层级创新包括：

（一）计算矩阵全面扩容，第八代TPU双芯精准覆盖训练与推理场景

- TPU 8t：专为训练优化，采用突破性的芯片间互联（ICI）技术，单个超级舱可扩展至9600个TPU与2PB共享高带宽内存，处理能力是上一代Ironwood的3倍，能效比最高提升2倍；


- TPU 8i：专为推理优化，采用全新的Boardfly拓扑结构，单个舱可直接连接1152个TPU，片上SRAM较前代提升3倍，可将更大的KV缓存完全承载在芯片上，同时集成专用的聚合加速引擎，推理性价比较前代提升80%，能够以高性价比支持数百万并发智能体运行；


- NVIDIA GPU生态深化：除已上线的Blackwell与Hopper架构实例外，谷歌云将成为首批提供NVIDIA Vera Rubin NVL72的云厂商之一；


- Google Cloud Axion升级：今年1月推出的N4A Axion实例，性价比较同类x86实例提升100%，为智能体提供持续、高效的运行支撑；


- 网络优化型计算实例扩容：新增C4N与M4N系列，专为高流量智能体通信、高网络负载的电信5G核心网与企业数据库优化，C4N实例的每vCPU网络带宽较标准C4实例提升近4倍。

（二）存储与网络全面革新，适配智能体时代的极致性能需求

- 存储创新：Managed Lustre性能升级，可通过RDMA为A5X或TPU 8t提供10TB每秒的吞吐量，大幅加速训练流程；Rapid Storage吞吐量从6TB/秒提升至15TB/秒，全面提速AI训练与推理工作负载；推出Smart Storage，为非结构化数据赋予语义含义，为企业知识图谱提供底座支撑；


- 网络创新：推出全新专用AI优化网络Virgo Network，可将NVIDIA Vera Rubin NVL72系统或TPU 8t超级舱连接为具备数十万个加速器的巨型超级计算机，大幅加速全球顶尖前沿模型的分布式训练。

（三）计算服务与云原生能力升级，打造自主运行的智能体时代云平台

- 开源框架与推理引擎扩容，新增对TPU版Pytorch的原生支持，以及跨GPU与TPU的优化版vLLM支持；


- Google Kubernetes Engine (GKE) 新增多项能力，大幅加快AI推理工作负载的冷启动与横向扩展速度，新增智能体沙箱，单集群每秒可部署300个沙箱，首条指令执行时间低于1秒；


- 基于Model Context Protocol (MCP)，将每一项Google Cloud服务都转化为智能体可直接编排的工具，让智能体可借助谷歌数十年的遥测数据，自主排查基础设施问题；


- 将Gemini推理能力集成至遥测库中，实现系统自主根因分析，在人工发现问题之前，即可识别配置错误并完成修复。

四、数据架构重构：Agentic Data Cloud，为智能体AI打造原生数据体系

本次大会，谷歌云正式发布Agentic Data Cloud，完成了企业数据架构的根本性变革——从为人类规模构建的被动式“智能系统”，转向为主动、可信的智能体构建的“行动系统”，以AI原生架构释放企业数据价值，让智能体能够实时代表企业进行感知、推理与行动。

本次发布的Agentic Data Cloud全新能力包括：

- 跨云Lakehouse：基于Apache Iceberg标准化，支持企业将数据保留在AWS或Azure（将于今年晚些时候上线）中并实现即时查询，无需厂商锁定与数据迁移成本，为Databricks、Palantir、Salesforce Data360、SAP、Snowflake、Workday等平台提供零拷贝数据访问；


- Lightning Engine for Apache Spark：实时无服务器引擎，运行速度较开源方案最高提升4.5倍，针对大数据集的性价比较行业领先竞品最高提升2倍；


- Data Agent Kit：在IDE、Notebook与智能体终端中，提供基于Gemini的数据科学创作体验，为数据从业者提供Python、Spark与SQL的意图驱动式开发能力，只需陈述业务目标，即可自动完成全流程开发工作；


- Knowledge Catalog：构建覆盖企业全业务的统一、动态上下文图谱，借助Smart Storage与Object Context API，在智能体访问前就为Google Cloud Storage中的文件完成标记与元数据补充，再通过Gemini自主完成标记、逻辑定义与全企业复杂关联关系映射，填补智能体缺失的语义定义能力；


- 面向企业洞察的Deep Research Agent：融合研究与分析能力的自主智能体，除对接企业文档与SaaS系统外，现已连接BigQuery等数据平台，全面覆盖结构化与非结构化数据，可解答供应链中断根因、区域财务审计等复杂业务问题，提供此前需要数周人工工作才能完成的引用标注与精准分析。

Flipkart、Lowe’s、Meesho、美国运通、拜耳作物科学、麦格理银行、沃达丰等企业，已通过Agentic Data Cloud实现了数据价值的全面释放。

针对AI时代企业面临的混合多云攻击面扩大、AI智能体成为攻击新目标、攻击者利用AI发起更复杂攻击的三重挑战，谷歌云在本次大会上发布Agentic Defense，通过一套网络安全平台，整合谷歌威胁情报与安全运营能力，以及Wiz的云及AI安全平台，实现全环境威胁的预防、检测与响应，为Agentic Enterprise打造全链路安全防护。

（一）Agentic SecOps：用威胁情报为智能体防御赋能

- Dark Web Intelligence：基于谷歌威胁情报团队的暗网专业能力，借助最新的Gemini模型为企业构建精细化安全画像，内部测试显示，其可对每日数百万条外部事件进行分析，准确率达98%，仅筛选出真正对企业有影响的核心威胁；


- Threat Hunting Agent：借助谷歌海量威胁情报知识库，让安全团队能够主动搜寻可绕过传统防御的新型攻击模式与攻击者行为；


- Detection Engineering Agent：为威胁场景生成持久化检测规则，将检测规则创建从手工工艺转化为自动化流程。

（二）Wiz全栈安全能力升级：跨任意基础设施保护AI与云应用

- Wiz AI Application Protection Platform (AI-APP)：为AI应用的基础设施、数据、访问、模型、智能体、应用全层级，提供从代码到运行时的全链路安全防护，覆盖企业所有开发环境；现已支持Databricks，以及AWS Agentcore、Gemini Enterprise Agent Builder、Microsoft Azure Copilot Studio、Salesforce Agentforce等智能体开发平台，同时可对接Apigee、Cloudflare、Vercel等服务，补充外部攻击面上下文；


- Wiz Red Agent：以AI级速度与规模模拟资深安全研究员，推理应用行为、实时调整攻击策略，验证Web应用与API中的可利用风险；


- Wiz Blue Agent：跨云遥测、运行时信号与身份上下文收集证据，调查威胁并评估严重程度，提供完整调查逻辑，助力企业快速解决威胁；


- Wiz Green Agent：内置调查与修复引擎，持续分析企业最高风险问题，整合Wiz全量上下文识别风险根因与最优解决方案，提供环境专属的分步修复指导；


- Wiz Agentic Workflows：全新云与AI安全编排中心，整合Wiz丰富上下文、AI智能体分析能力与可自定义拖拽界面，让安全团队可定义全工作流程，明确智能体执行规则与人工介入场景。
