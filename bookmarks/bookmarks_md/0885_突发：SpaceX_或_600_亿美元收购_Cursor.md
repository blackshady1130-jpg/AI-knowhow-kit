---



刚刚，SpaceX 发了一条推文，信息量巨大。

![SpaceX 官宣与 Cursor 合作](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FZKqVLiaIpzFknBNBVvSkFicedyJCTyvzuBhRGdCmREX0xPUrr3mjye9rW6TAkQD9UgrEwbwriaFt4bGnHwnRKbzcOibJ9VM3QHiaj0Eiapm1PeNhw%2F640%3Ffrom%3Dappmsg)
SpaceX 官宣与 Cursor 合作

SpaceXAI 宣布与 Cursor 深度合作，打造「世界最好的编程和知识工作 AI」。


合作的核心是：Cursor 的产品和百万级开发者用户群，加上 SpaceX 的 Colossus 超级计算机，等价于一百万张 H100。
![两个选项，都不便宜](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FZKqVLiaIpzFniaibXjlJcrAXxUFGKqExiaMOrpOEoxpdkxcPApS74IqO7TpPRAhiauXDPhZVqV5xd6Uic82chIQrCibsxRzKnK0FQJ75IUm5KQGkDI%2F640%3Ffrom%3Dappmsg)
两个选项，都不便宜

而交易条件更是相当的劲爆：**Cursor 已授予 SpaceX 今年晚些时候以 600 亿美元收购的权利，或支付 100 亿美元作为合作费用。**


换句话说，马斯克给自己留了两个选项：要么掏 600 亿买下 Cursor，要么花 100 亿「先用着」。
01
## 为什么是 Cursor


Cursor 这家公司的增长速度，应该用「离谱」来形容。


2025 年 1 月估值还是 25 亿美元，到 2025 年 11 月就涨到了 293 亿，再到 2026 年 4 月最新一轮融资估值已经达到**500 亿美元**。四年的公司，年化收入突破了**20 亿美元**，其中 60% 来自大企业客户。


日活超过 100 万，付费用户超过 100 万，超过半数财富 500 强公司在用。


但 Cursor 有一个结构性的「软肋」：它没有自己的基础模型。


目前 Cursor 的 AI 能力主要依赖 Anthropic 的 Claude 和 OpenAI 的 GPT。它本质上是一个产品层公司，模型能力完全受制于供应商。就像一家餐厅做得再好，食材全靠别人供货，这生意终究不太踏实。


这也是为什么跟 SpaceX 的合作对 Cursor 来说如此关键。

![食材全靠别人供](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FZKqVLiaIpzFlbMsbGuSOXdcluStrQzuEsXctQTeRSWr0NuD21aZRoN0oDXn3LrcTF5PvEeMGCV9a380AoDPMQI75BVJdpFFOILWSbEeLMdI8%2F640%3Ffrom%3Dappmsg)
食材全靠别人供

Cursor CEO Michael Truell 表示，SpaceX 的 Colossus 超级计算机将帮助 Cursor 「scaling up Composer」，也就是训练自己的模型。


其实合作的伏笔，早就已经埋下了。


xAI 一直在向 Cursor 出租算力，用数万张芯片帮 Cursor 训练模型。更值得注意的是，Cursor 的两位高级工程师 Andrew Milich 和 Jason Ginsberg 前不久跳槽去了 xAI，直接向马斯克汇报。
02
## 万亿合并


要理解这笔交易的逻辑，得先回看今年 2 月那场史上最大的合并。


2026 年 2 月，SpaceX 正式收购了 xAI，两家公司合并后估值达到**1.25 万亿美元**，其中 SpaceX 估值 1 万亿，xAI 估值 2500 亿。这是人类历史上金额最大的企业合并。


马斯克在博客中解释了合并的理由：**建造「轨道数据中心」**。


通过整合 Starlink 的全球卫星网络和 xAI 的大模型，SpaceX 计划把大规模计算搬到太空，利用持续的太阳能和自然散热。听起来像科幻片的剧本……但马斯克嘛，就是这样的人。

![把算力搬到天上去？](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FZKqVLiaIpzFl6EOG0TWeTOXfVQacS8qQMpLVBXL07fQnmKj07qnmVwNvFA7icjCBkx7O4djBybdglHk7207af1DrLORZDSQeHNXaAoFdDnkww%2F640%3Ffrom%3Dappmsg)
把算力搬到天上去？

合并完成后，SpaceX 计划在 2026 年年中进行 IPO，预计估值 1.75 万亿美元，将成为史上最大 IPO。


而在 IPO 前夕宣布收购 Cursor 的选项……这多少，就有点意味深长了。


600 亿美元的收购标的，对于一家即将上市的万亿公司来说，既是技术布局，也将是给投资者讲故事的筹码。
03
## Grok 的野心


马斯克对 AI 的执念，其实一直集中体现在 Grok 这条产品线上。


Grok 4 于 2025 年 7 月发布，在编程基准测试中表现抢眼：SWE-bench 得分 75%，LiveCodeBench 排名第一（79.4%），甚至在 Vending-Bench 模拟经营测试中净资产达到 $4,694，是 Claude Opus 4 的两倍多。


不过 Grok 4 也有明显短板。128K 的上下文窗口远小于 Gemini 的百万级别，目前还只支持文本输入，响应速度偏慢，简单数学题要 31 秒，复杂任务超过两分钟。


目前最新的是 Grok 4.3 beta，4 月刚上线，面向 Heavy 订阅用户（$300/月）。


而真正让外界关注的，是还在训练中的**Grok 5**。


6 万亿参数，Mixture-of-Experts 架构，150 万 token 上下文窗口，原生支持文本、图片、视频和音频。训练基础设施是 Colossus 2，超过 55 万张 GB200/GB300 GPU，2 吉瓦级集群。
![马斯克 AGI 概率推文](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FZKqVLiaIpzFmA7bfr0j6zFYHgdpsfmFTqkB8a9MUVPkhfK8BpvBX3mxkEMrgRZDwaReqda9DibAUN5jCuGQI1z8lHvp7b41bSaRiazjAaC1FJc%2F640%3Ffrom%3Dappmsg)
马斯克 AGI 概率推文

马斯克去年 10 月就发了一条引发广泛讨论的推文：


“我估计 Grok 5 实现 AGI 的概率目前是 10%，并且还在上升。


后来他的措辞进一步升级，直接声称「Grok 5 就是 AGI」，没有任何限定词。


Grok 5 原计划 2026 年 Q1 发布，但已经跳票了。目前仍在 Colossus 2 上训练，业界普遍预期 Q2（5-6 月）才会有公开测试版。
04
## 编程 AI 大战


SpaceX 盯上 Cursor，说到底是因为 AI 编程已经成了最激烈的战场之一。
![AI 编程工具大赛跑](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FZKqVLiaIpzFl7ibW0RvkXPP6oMUicktf4iaib4sIoZic0jibFwE7qzOicdBuZIBK3BJWhrPeuyQEk7umeI6xiazNc1ubCSrUzqWMIBpEHRTniaUWLKtKc%2F640%3Ffrom%3Dappmsg)
AI 编程工具大赛跑

**OpenAI Codex**在 4 月 16 日发布了一次大更新。Codex 现在可以操控你的电脑桌面，多个 Agent 并行工作，还能通过 SSH 连接远程开发环境，内置浏览器方便前端调试。新增了 90 多个插件，包括 JIRA、GitLab、Databricks 等企业工具。OpenAI 还给 Codex 加上了记忆功能和自动调度，它可以自己安排后续任务，跨天跨周持续工作。截至 4 月，Codex 周活开发者超过**300 万**，较 3 月初翻了近一倍。


**Anthropic Claude Code**也没闲着。最新的 Opus 4.7 在 SWE-Bench Pro 上得分 64.3%，比 Opus 4.6 提高了近 10%。桌面应用也做了大改版，加入了集成终端、文件编辑器、diff 查看器和 SSH 连接。Anthropic 还推出了 Cowork，算是 Claude Code 的「大众版」，让非开发者也能授权 AI 操作文件夹、编辑文件、生成报告。


而就在刚刚，Anthropic 还悄悄把 Claude Code 从 Pro 订阅中移除了，最低要 Max 5x 才能用。

![Claude Code 订阅变更](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FZKqVLiaIpzFnccVpLEjwvFJHcicryeCdDCVYK1EpYX0NAJ7OcmAf4UO9z2nKT3zZHCwJnr6A11MltlGx1pYicEgfnsGf11yPTQxlW7LVseHpvw%2F640%3Ffrom%3Dappmsg)
Claude Code 订阅变更

在 2026 年 1 月的开发者调查中，29% 的开发者在工作中使用 GitHub Copilot，18% 使用 Cursor，18% 使用 Claude Code。整个 AI 编程工具市场规模在 60 亿到 95 亿美元之间。
05
## 中国选手


而另一边，中国的模型们也在编程赛道上狂卷。
![编程能力：追平世界顶尖](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FZKqVLiaIpzFnWbico5FfltOE8nbrlvSWodjyRPsF4bXZJAF1UcOnjR4ib9Ypialia6UyDNjCPxySia2P2PialJrcoIRCrRZ8fsggccniaLsB3fG48rU%2F640%3Ffrom%3Dappmsg)
编程能力：追平世界顶尖

**通义千问 Qwen3.6**在 LM Arena 盲测中追平了 GPT-5.2 和 Gemini 3.0 Pro，对话、编程、视觉理解、Agent 四个维度全面对齐，全球排名靠前。


**智谱 GLM-5.1**达到了 Claude Opus 4.6 编程能力的 94.6%，在 SWE-Rebench 上得分 62.7%，订阅价格只要 $3/月。


**MiniMax M2.7**在 PinchBench 上拿到 86.2%，紧追 GLM-5 和 GPT-5.4（均为 86.4%），而 API 价格只有 $0.30 输入 / $1.20 输出，性价比极高。


最新的**Kimi K2.6**更是力压 GPT-5.4(xhigh) 和 Claude Opus 4.6，直接杀进了全球第一梯队。


字节的**豆包 2.0 Code**也在加速追赶，在 ICPC 编程竞赛中拿到金牌级成绩，深度集成到字节的 AI 编程工具 TRAE 中。


而**DeepSeek**，仍然非常值得期待。


V3.2 于今年 1 月发布，用国产芯片（海光 DCU + 寒武纪 MLU）完成了训练，彻底脱离了 NVIDIA CUDA 生态，训练成本降低 60%。创始人梁文锋透露，**DeepSeek V4 将于 4 月下旬正式发布**，1 万亿 MoE 参数，百万 token 上下文，SWE-bench 得分 81%，API 价格低至 $0.30/百万 token。


更关键的是，据透露，V4 将运行在华为最新芯片上。


**一句话概括：中国的开源和闭源模型，在编程能力上已经追平了世界顶尖水平。**
06
## 600 亿的赌注


回到 SpaceX 这笔交易。


600 亿美元买一个没有自研模型的编程工具公司……值吗？


从产品维度看，Cursor 是 AI 编程赛道的头部玩家，增长曲线陡峭，开发者心智占有率高。从战略维度看，xAI 的 Grok 模型虽然在通用推理上表现不错，但在编程场景下一直缺乏有效的「最后一公里」产品。OpenAI 有 Codex，Anthropic 有 Claude Code，而 xAI……什么都没有。


Cursor 补上了这块拼图。

![最后一块拼图](https://images.weserv.nl/?url=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FZKqVLiaIpzFmo6kYtOwc0OnV0ibbMy8Buuz87wx1rlBHRicM47iclbBNJdFmoH2872OLSFkRKx6jAqFdWjeoqb4WPH2DOn2Rssh92Cjia8ekQjns%2F640%3Ffrom%3Dappmsg)
最后一块拼图

况且 SpaceX 还给自己留了退路：如果 Cursor 的模型训练不如预期，或者市场格局发生变化，花 100 亿美元买个「合作经历」也不亏。


不过也有人担心，这笔交易更像是 IPO 前的叙事工程。毕竟，在一家即将以 1.75 万亿美元估值上市的公司里，600 亿美元的收购选项，讲出来就值不少市值。


不管怎样，AI 编程这条赛道，已经从技术竞争，变成了一场资本、算力和生态的全面战争。


**而马斯克，至今仍然坚定地认为，Grok 5 实现 AGI 的概率是 10%，**


**并且还在上升。**
