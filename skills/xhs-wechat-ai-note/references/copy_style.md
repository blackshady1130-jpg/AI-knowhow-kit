# Copy Style for AI行业判断笔记

Use this reference when writing Xiaohongshu or WeChat copy for public AI industry judgment notes.

## Core Positioning

- This is a judgment note, not news aggregation.
- One post should answer one question or test one reusable frame.
- The author voice is calm, concrete, mechanism-first, and boundary-aware.

## Common Structure

```text
标题：一句判断

发生了什么：
1-2 句交代材料、事件、模型发布或数据点。

我的判断：
2-4 点说明机制、控制点、商业含义或评测边界。

边界：
哪些地方不能过度外推，哪些信息还需要验证。

最后问一句：
给读者一个可复用问题、检查清单或判断句。
```

## Xiaohongshu Copy

Use when the user wants social image-text posting.

- Title: 18-28 Chinese characters when possible.
- Opening: first 3 lines must state the judgment.
- Body: 4-7 short paragraphs or bullets.
- Tone: direct, readable, not academic.
- End: one question or checklist.
- Hashtags: keep specific and restrained.

Example shape:

```text
标题：能被 Benchmark 衡量的工作，迟早会被商品化

今天这条不是在说 benchmark 没用，而是在说：公共 benchmark 其实是一张商品化地图。

1. 能稳定打分的任务，会被模型公司反复训练。
2. 有免费 verifier 的场景，价格会更快被打下来。
3. 应用层真正难复制的部分，往往在私有流程、权限、责任和验收里。

所以判断一个 AI 应用，别先问“模型能不能做”，先问：
这个结果谁验收？失败谁兜底？数据和 workflow 会不会沉淀？
```

## WeChat Copy

Use when the user wants a public-account draft.

- Title can be longer and more explanatory.
- Start with context, but do not overdo macro background.
- Use section headings.
- Keep evidence and boundary clearer than Xiaohongshu.
- End with a reusable framework or next question.

Recommended sections:

```text
标题

一、发生了什么
二、为什么这件事重要
三、我的判断
四、边界和后续观察
```

## Public Safety

- Remove current company name, internal org details, private project facts, and private source paths.
- Convert internal phrasing into public-safe category phrasing.
- If a number comes from a private or unverified source, do not publish it as fact.
- Keep “我判断 / 我倾向于认为 / 这更像是” for inference.

## Avoid

- “重塑格局”“赋能千行百业”“未来可期” without mechanism.
- Multiple unrelated news points in one post.
- A title that only says what happened.
- Turning every boundary into weak language; make the main judgment clear, then put caveats in one boundary section.
