# 站点数据同步设计

## 目标

把已经进入 `notes/AI行业扫描_keywords.jsonl` 的 #415–#424 同步到公开站点，并让 README 和网页准确区分两类时间：Notes 数据同步时间、七篇主题文章最后复核时间。

## 本轮范围

- README 的公开索引改为“更新至 2026-08”，Notes 数量更新为 424，并补充网页版入口。
- 为 #415–#424 添加一至三个已有主题分类。
- 重新生成 `site/data.json`，保留 Notes 原文中的 `why`，不改写作者判断。
- 七个主题增加 `review_updated_at` 元数据，当前统一记录为 `2026-08-02`。
- 页脚显示“Notes 更新于”；主题文章页同时显示“文章复核”和“Notes 同步”。

## 明确不做

- 不修改 `site/reviews/*.md` 七篇文章正文。
- 不修改 Notes 原文或既有 comments/why。
- 不改页面布局、配色、组件结构和发布工作流。
- 不合并到 `main`，不推送 GitHub Pages。

## 数据口径

- Notes 数量以 `notes/AI行业扫描_keywords.jsonl` 为准。
- 站点数据由 `site/build_data.py` 生成，`site/data.json` 不手工维护。
- `meta.generated_at` 只代表站点 Notes 数据生成日期，不能代表主题文章已在同一天复核。
- 主题文章复核日期来自 `site/topics.json` 的 `review_updated_at`。
