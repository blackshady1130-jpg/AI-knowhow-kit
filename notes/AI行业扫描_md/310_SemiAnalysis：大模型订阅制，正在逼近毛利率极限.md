研究机构 SemiAnalysis 针对 Anthropic 与 OpenAI 的订阅计划进行压力测试，发现高频编码等长程任务极易耗尽周额度，使厂商毛利率急剧转负。测试显示，用户购买 200 美元/月的 ChatGPT Pro 订阅（包含 20 倍额度），最高可消耗等值 14000 美元的 API Token 资源，而同等价位的 Claude Max 订阅（包含 20 倍额度）也可消耗等值 8000 美元的 Token 资源。

若假设两家公司的 API 列表价毛利率为 75%，不同平均使用率对应的订阅毛利率变化剧烈。对于 200 美元/月的 ChatGPT Pro 订阅，一旦平均使用率超过 5.7%，毛利率即转为负值。若使用率达到 100%，OpenAI 的毛利率将跌至 -1650%。对于同档的 Claude Max，使用率超过 10% 就会跌破盈亏平衡点，而使用率达 100% 时的毛利率为 -900%。

即便是 20 美元/月的普通订阅，最大等值 API 消耗也远超定价。ChatGPT Plus 计划最高可消耗等值 700 美元 Token，Claude Pro 则为 400 美元，盈亏平衡点分别为 11.4% 和 20% 的使用率。由于直接削减订阅额度极易引发舆论反弹，SemiAnalysis 预测，大模型厂商未来更有可能将新模型或高级功能限制为 API 专属渠道，以隔离高成本损耗。

这也印证了 Anthropic 对最新旗舰模型 Claude Fable 5 的计费调整。订阅版用户在 6 月 22 日前可免费试用，自 6 月 23 日起则需使用消费点数额外支付，直至未来算力充足时才会重新纳入常规订阅。
