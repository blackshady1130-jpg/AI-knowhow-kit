现在每周有超过 500 万人使用 Codex。Codex 最初是作为软件开发工具推出的，但它正越来越多地用于更多类型的工作。过去一个月，分析师、营销人员、运营人员、设计师、研究人员、投资者、银行家等非开发者，占 Codex 新用户的 40%⁠。

今天，我们推出了用 Codex 完成更多工作的全新方式：插件可让 Codex 适配你的角色和工具，站点可将你的工作转化为托管的交互式网站和应用，并通过 URL 与工作空间共享；批注则可帮助你就地优化结果。

在 OpenAI 内部，非技术团队使用 Codex 构建内部应用、准备高管材料、创建仪表板，并将创意简报转化为符合品牌和设计约束的成果。在 Zapier，各团队使用 Codex 从 Slack、Google Docs 和 Coda 等工具中提取知识，再将这些上下文转化为复盘报告、事件响应计划和功能工单。在 NVIDIA，研究人员正使用 Codex 加速实验工作流，从寻找研究想法到为机器学习基础设施编写脚本。

让 Codex 按照你团队的工作方式运作

当 Codex 按照你团队的工作方式运作时，它最有用：连接你使用的工具，并随时准备创建你所需的材料。

插件可帮助 Codex 与你团队已在使用的工具、上下文和工作流协同工作。今天，我们推出六款新的角色专属插件，让 Codex 可用于更多类型的知识工作，无需编写代码：

每个插件都打包了相关应用、技能、说明和工作流。它们共包含 62 个热门应用和 110 项技能。
数据分析插件可帮助分析师和业务团队用数据回答问题。他们可以探索产品和业务数据，解释关键指标变化的原因，并使用 Snowflake、Databricks Genie、Hex 和 Tableau 等工具创建报告和仪表板，未来还会支持更多工具。
创意制作插件可帮助营销和创意团队将简报转化为可供审阅的素材。团队可以创建营销活动看板，制作和优化展示广告变体，并使用 Figma、Canva、Shutterstock、Picsart 和 Fal 等工具制作产品生活方式图或适用于电商的图片集。
销售插件可帮助销售团队将客户上下文带入推动交易进展的工作中。销售团队可以使用 Salesforce、HubSpot、Slack、Outreach、Clay、Rox 和 Actively 等工具，查找高优先级客户和信号、准备客户会议、完成跟进、更新客户记录、制定成交计划，并审查存在风险的交易。
产品设计插件专为将早期想法转化为团队可审阅的原型而构建。团队可以探索产品方向、审查用户流程、从实时 URL 制作原型，并让静态截图具备交互性，相关工作还可在 Figma 和 Canva 等工具中继续推进。
公开股票投资插件可帮助投资者理解市场和公司信息。他们可以利用来自 Moody’s、Daloopa、Datasite、FactSet、LSEG、S&P、PitchBook 和 Hebbia 的信息，审阅收益、比较公司、跟踪信号，并评估投资论点是在增强还是减弱。
投资银行插件可帮助银行家将研究和尽职调查转化为面向客户的材料。他们可以准备推介材料、分析可比公司和交易，并利用可信数据将尽职调查转化为建议。

用站点共享你的工作

工作并不总能被整齐地放进文档、电子表格或演示文稿中。借助站点，Codex 可以将想法、分析或计划转化为可供人们探索和使用的托管交互式网站或应用。

Codex 可以基于你提供的上下文进行构建——从文档和电子表格，到发布材料、财务模型，以及你在 Codex 中创建的工作。你可以通过 URL 将结果分享给工作空间中的任何人，让大家探索、使用并基于这些工作采取行动。

让 Codex 为即将到来的客户评审创建一个站点，它会生成一个交互式网页，包含该客户相关的产品更新、未解决问题、使用趋势和后续步骤。让它基于财务模型构建情景规划器，领导者就能比较各项假设，而不是逐个阅读文档中的标签页。让它把发布材料转化为一个动态中心，团队可在其中找到最新话术、里程碑、负责人和决策；并让 Codex 在细节变化时保持站点更新。

站点可以汇集让工作更易理解并付诸行动的各种形式：用图表说明变化，用表单收集输入，用跟踪器展示进度，或提供支持细节以辅助决策。团队无需让工作去适应单一工具或文件的限制，而是可以创建符合自身需求的体验。

用批注优化你的工作

Codex 已经允许你直接在应用内打开并处理文档、幻灯片、电子表格和站点。现在，借助批注，你可以指向想要优化的确切部分，并告诉 Codex 需要更改什么。

开发者已经在使用批注来优化代码、Markdown 文件，以及 Codex 在应用浏览器中创建的内容。现在，这种就地工作的方式扩展到了团队所做的更多工作中。

在站点中选择导航栏，然后让 Codex 更新字体。高亮投资论点中的一项主张，并询问 Codex 它的来源。标记幻灯片上的图表，并请求提供更清晰的标签。Codex 会将更新聚焦在你选择的部分，因此你可以优化工作，而无需从头开始或重做已经满意的部分。当第一版之后的工作需要判断、反馈和迭代时，批注会让 Codex 更有用。
