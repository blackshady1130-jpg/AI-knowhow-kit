## 一句话总览

这期访谈最有价值的地方，是把“中国模型正在追近美国”这个结论拆成了一组更可操作的机制：**算力约束促使实验室重做架构和基础设施，稳定的创始人意志塑造长期技术文化，开放权重使能力快速迁移到 Agent 与应用层，真实用户轨迹又反过来成为下一代模型最稀缺的数据。最终的竞争单位不再只是一个通用模型，而是人才、组织、模型、Serving、应用、环境数据和验证闭环组成的整套系统。**

孟醒对中美差异的判断并不是“中国更有效率、美国更有资源”这么简单。他真正强调的是，资源、人才流动、融资约束和创始人目标共同决定了一家实验室敢做什么、如何评估自己，以及能否承受短期落后。中国前沿团队的优势不来自“穷所以自然创新”，而来自少量高密度人才在明确目标下，被迫把每一单位算力转化为更高产出；美国实验室的优势也不只在算力，而在人才市场、资本、工具链和跨机构知识流动。

整场对话可以压缩成十个核心判断：

1. **中国前沿实验室不是同一种公司。** Moonshot、DeepSeek、Z.ai、MiniMax 和字节 Seed 在人才结构、产品边界、资本耐心和技术文化上差异很大，不能用“国产大模型”一概而论。
2. **组织文化本身就是模型 recipe。** 小团队、年轻人才授权、技术报告透明度、是否追求短期榜单，以及创始人愿不愿承受落后，都会直接进入最终模型。
3. **资源稀缺只是约束，不是创新原因。** 稀缺资源必须与高人才密度、明确问题和工程执行力结合，才会转化为架构与 Infra 创新。
4. **直接蒸馏最大的风险不只是合规，而是研发自我欺骗。** 团队可能获得很好的结果，却没有形成独立发现和继续爬坡的能力。
5. **开放权重对产业的第一波冲击发生在开发者和损益表，而不一定先发生在前沿研究者的认知里。** 应用公司会迅速切换和路由模型，研究团队却可能仍按旧竞争地图工作。
6. **token 使用量、token 收入和任务价值是三张不同的表。** 更便宜的开放模型可以让调用量不降，却让上游模型公司的收入承压。
7. **非代码白领工作的瓶颈不是上下文窗口，而是缺少稳定 verifier。** 人必须不断看结果、改目标，模型延迟因此直接决定反馈循环能跑多少轮。
8. **下一代 Neo Lab 更像“先有超级应用和专有轨迹，再训练专用模型”。** 新方法未必来自全新的预训练架构，更可能来自前沿实验室拿不到的真实任务数据。
9. **训练数据正在从静态样本迁移为可交互环境。** 环境能让模型尝试、失败、获得奖励并形成轨迹，是 Agent 后训练和评测的新生产资料。
10. **AI for Science 的核心障碍是 verifier 太慢、太贵、太晚。** 在药物研发里，最终反馈可能要到多年后的临床阶段才能出现，这与代码测试的即时反馈完全不同。

## 最高价值观点清单

### 1. 中美 AI 生态应先比较组织机制，再比较模型榜单

节目以美国和中国两组基础模型公司开场。美国一边是 OpenAI、Anthropic 等前沿实验室，一边是 Google、Meta 等大型科技公司；中国则同时存在创业实验室和字节、阿里等大厂。

但这个“创业公司对大厂”的分组仍然太粗。孟醒更关注四个底层变量：谁能稳定获得算力，谁能吸引并留住核心研究者，创始人给组织设定了什么目标，公司是否必须靠下一轮融资证明短期成绩。这四个变量往往比“公司是不是大厂”更能解释技术路线。

### 2. Moonshot 的稀缺资产，是目标连续性而非某一代模型

孟醒把 Moonshot 描述为高度理想主义、以 AGI 为长期目标的研究组织。公司经历过舆论高峰和低谷，但核心目标与组织气质没有明显改变。在快速追逐热点的行业里，这种连续性使人才知道自己加入的是一项多年任务，而不是一轮产品风口。

这并不证明长期目标一定带来商业成功。它的价值在于减少路线频繁切换，让架构、训练、Infra 和人才培养可以在同一方向上复利。K3 是这套组织方式的一次结果，不应被当作唯一证据。

### 3. 对年轻研究者的真实授权，比“年轻化”口号更重要

访谈特别强调 Moonshot 对年轻研究者和实习生的授权。据嘉宾观察，一些很年轻的成员能够获得算力、资源和组件所有权，参与 K3 的关键模块。重点不在年龄本身，而在组织是否把真实问题和失败成本交给他们。

这套机制解决的是前沿研究的人才冷启动：如果新人只能做边缘任务，他们永远无法积累大规模训练的判断；如果组织给出真实责任，模型项目本身就成为人才培养系统。

### 4. 小团队的价值是降低上下文损失，但它不是免费的优势

孟醒估计 Moonshot 当时团队不足 400 人、可能约 300 人，并认为公司有意控制规模，让成员更容易理解彼此在做什么。这个数字没有官方披露，应视为嘉宾口径。

小团队可以减少沟通层级和目标漂移，却也会限制并行项目数量、产品覆盖和全球商业化能力。真正值得关注的不是人数小，而是组织是否把有限人力集中在最有杠杆的技术问题上。

### 5. K3 的难点不是把参数做大，而是在大规模训练中同时更换关键结构

Moonshot 官方披露，Kimi K3 是 2.8T 参数的开放权重 MoE 模型，采用 Kimi Delta Attention、Attention Residuals 等结构。孟醒关注的是工程风险：在较小模型上验证过的结构，放到接近 3T 参数规模时仍可能失效，甚至在短期内拖累性能。

因此，K3 的信号不只是“模型更强”，而是团队能把研究原型、训练稳定性、并行系统和 Serving 约束同时装进一次大规模训练。这种系统整合能力比单项论文创新更难复制。

### 6. Moonshot 与 DeepSeek 的相似处，是研究导向和高强度执行

孟醒认为两家公司大约“八成相似、两成不同”，并判断它们可能在开放权重模型的领先位置上交替。这里的“相似”主要是人才密度、理想主义、工作投入和研究型文化，不意味着架构、资本结构或产品路线相同。

这个判断的决策意义是：观察中国开放模型不能只押一家公司。两支独立团队在不同结构上并行迭代，会形成互相验证、互相刺激的技术生态。

### 7. 资源约束只有与优秀人才结合，才会转化为效率创新

“缺算力逼出创新”很容易被浪漫化。孟醒的完整意思更严格：资源稀缺会迫使团队解决效率问题，但只有当问题足够重要、人才足够强、执行周期足够长时，约束才会产生世界级方法。

单纯削减预算更可能造成保守和失败。真正的机制是：有限资源提高每次实验的机会成本，团队因此必须更认真地设计架构、并行、通信、缓存与训练流程。

### 8. 中国团队的 Infra 创新，已经成为美国实验室的学习对象

孟醒称，他在美国前沿实验室交流时发现，一些基础设施研究者会认真研究 DeepSeek 和 Kimi 的方法，并对很年轻的中国研究者评价很高。这个观察不能外推为所有美国研究者的态度，但它纠正了“技术知识只从美国流向中国”的单向叙事。

更重要的是，DeepSeek 等团队通过较完整的技术报告降低了外界理解和复现成本。开放的不只是权重，还有一种向全球研究社区解释系统细节的能力。

### 9. DSA 与 KDA 的关系，是共同目标下的不同工程答案

DeepSeek Sparse Attention 与 Kimi Delta Attention 并不是同一种机制，但都试图降低长上下文和推理的资源成本。嘉宾把这种关系描述为理念接近、技术路径不同。

这说明前沿模型竞争已经从单纯扩参数，进入“如何让注意力、专家路由、训练和 Serving 共同可扩展”的阶段。团队之间可以借鉴问题定义，却仍需独立解决自身模型和硬件条件下的工程约束。

### 10. 人才流动速度，会改变公司文化能保存多久

孟醒观察到，美国前沿实验室之间的人才迁移非常频繁，且覆盖资深研究者；中国实验室之间的横向流动相对少，人才更常在原组织内部成长、创业，或迁往美国。

高流动性有利于知识扩散和快速重组，也会削弱单家公司的长期风格；较低流动性让创始人的目标与方法更容易沉淀成组织个性，却可能减少跨机构经验交换。两者没有绝对优劣，关键是流动如何影响知识复用和执行连续性。

### 11. 中国实验室的差异，很大程度上来自创始人选择什么样的人

孟醒认为，梁文锋、杨植麟、唐杰等创始人的气质和学术或产业背景，会影响组织吸引哪类研究者、如何分配资源，以及怎样定义“好工作”。创始人不只是融资和战略角色，也是人才筛选器与研究品味的源头。

这使模型公司难以通过简单挖人完成复制。招聘可以带来技能，却不一定带来一套共享的目标、评估标准和合作方式。

### 12. DeepSeek 的人才策略，是在本土年轻人才上做长期下注

据孟醒观察，DeepSeek 更愿意吸收中国高校中尚未被市场充分定价的年轻人才，而不是以高价争夺美国顶级实验室的明星研究者。其优势不是工资更高，而是给新人真实规模、真实问题和较长时间。

这种策略的风险是培养周期长、早期判断难；回报是人才与系统共同成长，更容易形成不依赖外部明星的研究能力。它与 Moonshot 的年轻人才授权有相似之处，但组织来源和资本结构不同。

### 13. DeepSeek 的开放价值包括“可学习性”，不只包括“可部署性”

开放权重让开发者可以部署模型，较完整的技术报告则让研究者理解能力从何而来。孟醒特别肯定 DeepSeek 对训练和 Infra 细节的披露，认为一些美国研究者会从中发现原先没有尝试过的方法。

开放模型的生态影响因此至少有两层：一层是价格和部署选择权，另一层是让架构、系统和训练经验成为公共讨论对象。只看 API 价格会低估第二层价值。

### 14. “美国训练规模更大，所以所有方法都应先被美国发现”是错误推理

更大算力让团队探索更大模型，却不保证它会探索所有局部工程问题。算力充足的组织可能优先扩展已验证路线，算力有限的团队则被迫研究通信、并行、稀疏化、缓存和数值稳定性的边界。

创新空间并不是一条单轴曲线。不同约束会让团队进入不同搜索区域，所以较小实验室仍可能找到大实验室没有优先寻找的方法。

### 15. Z.ai 更像能力与产品线都较宽的完整 AI 公司

孟醒认为，Z.ai 受益于清华系研究积累和较大的团队规模，覆盖语言模型、Coding、Computer Use、多媒体和多类产品。它与 Moonshot、DeepSeek 的区别，不是“研究弱、产品强”，而是组织同时承担更多方向，资源配置更接近完整平台公司。

宽产品线可以带来更多用户入口和数据，也可能造成注意力分散。判断这种路线是否有效，应看不同产品是否共享模型、数据、Serving 和分发能力，而不是只统计产品数量。

### 16. MiniMax 的能力结构反映了其产品和人才来源

嘉宾把 MiniMax 的早期优势放在 Serving、陪伴类产品、多媒体和商业化执行上，并提到其组织曾吸引不少来自字节体系的产品、开发和 GTM 人才。这种人才组合会自然强化产品节奏、消费体验与分发能力。

因此，不能只用数学、推理或 Coding 排名评价 MiniMax。它的战略问题是，多媒体和产品优势能否转化为长期数据与模型差异，而不是能否在所有通用 benchmark 上同时领先。

### 17. 不同实验室应放在同一组维度上比较，而不是各贴一个标签

“Moonshot 理想主义、DeepSeek 工程强、Z.ai 平台化、MiniMax 产品强”只是起点。更严谨的比较应持续追踪：核心人才来自哪里，模型训练与产品团队如何协作，哪些数据可以回流，是否能承受长期研发，开放策略服务什么商业目标，Serving 是否支持真实使用。

标签容易把动态公司冻结在某一时点。机制比较才能解释它们下一步可能怎样变化。

### 18. 拒绝直接蒸馏的价值，是保护研发测量系统

节目讨论了一则媒体报道：张一鸣要求字节 Seed 不把从其他前沿模型直接蒸馏作为追赶捷径，即使短期落后。孟醒称这是一项“勇敢的决定”，因为直接蒸馏确实可能快速提高结果。

他的核心担忧不是道德表态，而是测量污染：团队可能误以为自己的架构、数据和训练系统已经奏效，实际增益来自外部教师。下一代任务变化或接口关闭后，组织会发现自己没有独立爬坡能力。

### 19. “蒸馏”至少要分成直接能力提取与广义合成数据学习

孟醒区分了两类操作。第一类是用覆盖用户分布的 prompts 大规模调用前沿模型，收集答案甚至推理痕迹，再训练学生；第二类是研究者借助模型生成、筛选和改写合成数据，模型能力以更间接方式进入数据生产。

两类方法在授权、依赖程度和技术含义上不同。把所有合成数据都叫“偷能力”过于宽泛，把直接提取推理轨迹说成普通数据增强也过于轻描淡写。

### 20. 能否承受短期落后，本质上是资本结构问题

当一家实验室必须持续融资，它很难公开接受数年落后，因为模型排名、用户增速和融资叙事彼此绑定。字节和 DeepSeek 具有相对独立的资金来源，因此更有条件牺牲短期榜单，换取内部能力建设。

这不代表资金独立就一定选择长期主义。它只是提供了选择权。真正决定结果的仍是负责人是否愿意使用这项选择权，以及组织是否有办法判断“落后是在积累，还是单纯做错”。

### 21. 开放权重的冲击，可能先反映在 Agent 开发者的模型路由上

孟醒在湾区交流中的意外发现是，一些前沿实验室研究者很少亲自试用 K3 等中国开放模型；与此同时，Agent 公司和开发者已经开始切换模型或建立混合路由。

这产生了一种认知时差：最接近模型研究的人未必最先改变，最受 token 成本影响的应用公司反而最敏感。产业分析不能只访问研究负责人，也要观察 API 路由、开发工具和真实工作负载。

### 22. 模型迁移不必是全量替换，可以把强模型变成稀疏审阅者

嘉宾举例，应用可以用 K3 或 DeepSeek 承担主要代码生成，再让 Claude 复核高风险结果。开放模型负责大部分 token，昂贵闭源模型只在关键节点提供判断。

这比“谁替代谁”更接近未来系统：模型被拆成不同角色，按任务难度、置信度、延迟和价格调用。闭源模型即使保留能力优势，也可能从默认执行者变成按需专家。

### 23. 对普通任务而言，头部模型已经出现感知同质化

孟醒认为，除前沿模型研发、高难代码和数学等任务外，普通用户很难稳定区分多个头部模型。甚至同一模型家族的新旧版本，在不同任务上也可能各有胜负。

这并不等于模型能力已经商品化。它意味着用户支付意愿会更多由产品入口、速度、稳定性、工具集成和价格决定，而不是由平均 benchmark 的微小差距决定。

### 24. 开放模型可以让 token 量保持增长，同时压低上游收入

节目提出一个值得单独建模的情景：如果总 token 使用量持平或增长放缓，但用户从昂贵闭源模型转向便宜开放模型，行业 token 收入会下降。即使调用量不变，上游收入结构也会改变。

因此，研究模型公司不能只看 token 增速。还要看平均实现价格、缓存占比、模型组合、渠道分成、推理成本和每项任务需要的总 token。

### 25. 研究者不重视开放模型，可能是组织盲区而非理性忽略

前沿实验室的研究者可能认为自己的任务远高于开放模型当前能力，因而不愿投入时间评估。但如果开放模型已经在大量中等难度任务中替代闭源调用，这种忽略会让研究团队低估商业压力和外部创新。

更健康的机制是分层评估：研究团队看方法和能力边界，产品与商业团队看迁移、留存和价格，Infra 团队看吞吐与部署。任何单一视角都不足以判断竞争影响。

### 26. Coding 能长时间自治，是因为目标和 verifier 相对清晰

代码任务可以预先定义仓库状态、测试、编译结果和性能门槛。只要 Harness 合理，Agent 可以运行很久，持续试错，用户第二天再检查结果。

这解释了 Coding Agent 率先形成高 token 消耗和高渗透。关键不是程序员更愿意尝试 AI，而是软件工程天然提供了可执行环境和机器可读反馈。

### 27. PPT、报告等白领任务的瓶颈，是目标在看见结果后才形成

制作 PPT 时，用户很难事先把“好看、重点突出、适合这位老板”写成完整规则。第一版出来后，人会重新理解问题、修改目标、补充信息，再发起下一轮。

因此，人不是单纯审批者，而是任务定义的一部分。Agent 很难像写代码一样在无人值守状态下连续运行数小时，因为每轮结果都会改变用户下一步想要什么。

### 28. 对人机共创任务，延迟直接决定需求上限

如果每轮 PPT 或报告修改需要十分钟，用户一天只能进行少量迭代；如果十秒得到可检查结果，人机循环可以显著增加。速度在这里不是体验优化，而是决定总使用量和最终质量的核心变量。

这也说明“更强但更慢”未必适合全部白领任务。路由器需要在智能、延迟和成本之间按工作阶段切换，而不是始终调用单一最强模型。

### 29. 企业 AI 采用比个人采用慢，主要是组织系统没有同步更新

嘉宾估计，大企业要用两三年处理安全、隐私、合规、采购和内部推广。这个周期是经验判断，不是所有企业的固定规律。

企业采用慢并不等于员工没有需求。常见状态是个人先通过非正式工具完成工作，组织随后才补齐数据边界、权限和责任。这种时差会影响模型公司销售周期，也会制造灰色使用风险。

### 30. 视频模型的早期高价值用户更可能是 prosumer，而不是普通消费者

孟醒认为，Seedance 2.0 发布后的收入增长，早期主要来自广告、短剧和专业内容创作者。他们把视频模型放进工作流，按商业产出购买大量 API 或生成额度；普通个人用户的直接支出增长未必同样快。

这一区分很重要。消费端的传播热度与付费来源可能不同，投资者应看谁在生产内容、谁承担成本、谁能把生成结果变成收入。

### 31. Seedance 的竞争力来自数据、产品知识、分发和一次高风险算力下注

字节拥有视频数据、产品理解和分发渠道，这是明显先天条件。但孟醒认为，Seedance 2.0 的跃迁还来自一项当时并不稳妥的决策：大幅扩大视频模型训练规模，在 Coding 争夺算力的阶段仍为多媒体保留大量资源。

先天优势只有在资本配置上被兑现才有意义。Meta 同样拥有数据、人才和分发，嘉宾却认为其进展低于预期，这构成了一个反例。

### 32. 中国视频模型领先，不代表中国天然更擅长多模态

更准确的解释是，字节、快手等公司长期经营短视频，知道创作者需要什么，也能让模型直接进入内容生产链。美国前沿实验室把更多算力集中到 Coding，资源配置目标不同。

所谓国家差异，很多时候是企业资产和优先级差异。把 Seedance 的成功归因于“中国市场爱短视频”会漏掉模型规模、训练风险和产品闭环。

### 33. 生成视频的产品机会，先在特定内容类型上成立

嘉宾观察到，早期 AI 视频更适合特效密集、武侠、科幻等类型，因为模型擅长生成视觉奇观，却难以稳定表达细微情绪和高速人物交互。Seedance 2.0 在微表情、动作连续性和复杂运动方面的改善，扩大了可用内容边界。

这仍是产品观察，不是系统测评。真正的商业验证要看成片采用率、人工返工时间、角色一致性、单位镜头成本和版权风险。

### 34. “介于影视与游戏之间的互动内容”仍未找到稳定产品形态

孟醒此前期待一种中等交互、可无限生成的媒体：用户不像看电视那样完全被动，也不必像玩游戏那样持续高强度操作。但他在本次访谈中承认，这一形态的进展低于预期。

这个自我修正很重要。技术上可生成不等于用户愿意持续消费，互动叙事仍需解决内容质量、节奏、可控性和创作成本。单个爆款不能证明一个新媒介已经成立。

### 35. 新一代 Neo Lab 应该从应用和轨迹出发，而不是复制通用预训练

孟醒重新定义了 Neo Lab：它不一定是一群明星研究者先融资训练通用模型，更可能是一家公司先建立高频应用，积累独有用户轨迹，再通过后训练得到面向该任务的模型。

他以 Cursor 一类产品为范式。应用先理解真实工作分布，模型训练成为降低成本、提高任务表现和保护产品差异的手段，而不是公司的起点。

### 36. “专有数据”必须同时满足不可替代和任务聚焦

拥有日志并不等于拥有模型护城河。孟醒提出两个条件：数据应难以被前沿实验室或竞争者复制，并且最好来自明确垂直领域。法律、医疗等任务分布更窄，应用公司才有机会训练出在局部胜过通用模型的系统。

如果产品本身是通用搜索或通用 Agent，用户任务与前沿实验室覆盖范围高度重合，数据差异就不够强。此时自训模型可能只降低成本，未必形成独特能力。

### 37. 前沿模型的训练目标，仍受研究者个人经验偏置

基础模型团队通常由数学、代码和计算机科学背景的研究者主导。哪些数据值得买、哪些环境值得建、哪些 benchmark 值得追，很容易反映研究者熟悉的任务。

刚毕业的研究者可能很懂 Coding，却没有做过销售运营、会计、PPT 或大型企业协作。模型在这些场景表现不足，不一定是能力上限，也可能是训练目标没有接触真实工作。

### 38. 真正的工作环境比研究者想象的任务更重要

未来模型应在 Slack、Zoom、Salesforce 和各种垂直 SaaS 中被评估，因为那里包含真实目标、权限、协作和流程。静态题库或人工编造任务只能覆盖一部分能力。

应用公司拥有的最大资产，不只是输入输出文本，而是用户在软件中为完成目标走过的轨迹、修正、失败和最终结果。这些记录同时提供任务分布与近似 verifier。

### 39. 数据的基本单位正在从“样本”变成“环境”

传统数据是网页、标注答案或合成问答，训练前已经固定。环境型数据则提供工具、状态、目标和奖励，模型可以反复行动并通过强化学习形成策略。

因此，未来数据公司的交付物可能不再是一批 JSON，而是一套可重置、可观察、可评分的工作系统。其工程复杂度和单价都会远高于普通标注。

### 40. 环境难度可以沿“可观测性”和“状态变化”两条轴拆解

最简单的是静态、完全可观测环境，例如 CUDA kernel 优化：测试条件固定，实验可以重复。更难的是部分可观测环境，例如新员工通过 Slack 逐步理解老板的真实偏好，目标不会一次性写清楚。

再进一步是动态环境，例如交易、社交媒体或真实经营：Agent 每个动作都会改变后续状态，无法简单回滚到相同起点。环境越动态，离线 benchmark 越难代表线上表现。

### 41. Vending-Bench 的价值，是把“会推理”变成“能经营多久”

Andon Labs 的 Vending-Bench 让模型长期运营模拟自动售货机，处理进货、库存、定价和费用。单步任务并不难，难点是数百轮之后仍保持一致的状态理解和经营策略。

孟醒还提到从模拟自动售货机走向真实商店的实验。它揭示了环境数据的下一步：不只在浏览器沙盒里验证 Agent，还让模型面对真实供应、员工、客户和不可逆事件。

### 42. 数据公司正在分化为“人力交付”和“环境产品”两种经济模型

传统数据供应商按专家人数、工时和项目收费，销售依赖大客户关系。新一代公司则可能按 benchmark、环境和可验证任务包收费，一个复杂环境需要重建大部分云服务或企业软件，价格远高于普通标注。

两类公司都可能增长，但毛利结构、研发能力和客户黏性不同。按人头扩张更像专业服务，环境产品若能复用，则更接近软件和研究基础设施。

### 43. 数据公司的新竞争，是提前预测研究者三个月后需要什么

孟醒观察到，一些数据公司由研究者创业，优势不是更便宜地招标注员，而是理解前沿实验室下一阶段会攻哪个 benchmark、需要哪类环境和失败样本。

它们可能先推出 benchmark，形成行业关注，再出售相应训练数据或环境。这种模式增长快，却带来明显利益冲突：同一主体既定义考试，又出售提分材料。

### 44. Benchmark 可能同时是研究公共品、营销入口和数据销售漏斗

当 benchmark 制作者也是数据供应商，榜单影响力会直接转化为订单。外界需要追问：任务是否代表真实分布，测试集是否可泄露，训练数据是否与评测高度同源，模型提升是否迁移到未见任务。

这并不否定商业机构做 benchmark。它意味着 benchmark 的治理、数据隔离和外部复现，比单一分数更重要。

### 45. 中国数据公司也在从专家标注转向环境和评测

访谈认为，中美数据公司都曾从人类标注和高端专家数据起步，现在都在增加 benchmark、Agent 环境和训练任务。差异更多体现在客户预算、研究者创业密度、销售方式和前沿实验室需求节奏，而不是“海外做高端、中国做低端”。

这一判断与节目中嘉宾此前对数据行业的观察一致：高质量数据越来越像研发项目，而不是低成本劳务采购。

### 46. AI for Science 至少要区分“科学 Agent”和“科学基础模型”

第一类系统用通用模型阅读论文、设计实验、调用数据库、控制仪器、分析结果和撰写论文。第二类系统直接训练蛋白质、细胞、材料或物理世界的专用模型，用于结构预测、生成和模拟。

两者的技术栈和价值验证不同。科学 Agent 主要难在工具、工作流和实验连接；科学基础模型主要难在高质量数据、表示方法和真实世界验证。

### 47. 科学 Agent 容易做出演示，难做出被同行认可的新知识

接入文献数据库、搜索和实验设计工具后，做一个能运行的 AI scientist 并不困难。真正门槛是系统能否提出有价值的假设、设计可信实验，并产生可复现、能通过同行审查的结果。

通用模型并未专门学习每一种科学数据库和实验工具，团队往往仍要建立 workflow、guardrail 和人工检查。Agent 的完整链路越长，局部错误越容易累积。

### 48. 湿实验把 AI for Science 的反馈周期从秒级拉到天、月甚至年

代码和数学可以在线验证，实验生物学需要仪器、试剂、实验员和现实时间。Agent 可以完成文献综述和实验设计，却必须等待人类执行湿实验，训练闭环因此被切断。

如果实验平台能自动化、标准化并持续回传数据，科学 Agent 的价值才可能从研究助手升级为闭环研究系统。

### 49. Virtual Cell 的难点不是模型不够大，而是观测远远不够

在蛋白设计中，模型可以生成新的 binder；但要预测它在细胞中的真实作用，需要对复杂细胞状态建模。现实中对细胞的传感和干预数据远少于图像、文本或机器人数据，无法轻易支撑统一大模型。

蛋白质、抗体、抗原、酶和多肽的表示也不同。如何把多种生物实体和尺度放进同一模型，是数据和建模共同的难题。

### 50. 药物研发的最终 verifier 来得太晚

蛋白是否结合、细胞实验是否有效，只是中间验证。最终问题是药物进入人体后能否安全治病，而临床反馈往往要在项目启动多年后才出现。

这使 AI for Drug Discovery 面临严重的信用分配问题：团队很难快速判断模型改善是否真正提高临床成功率。任何短期“发现效率提升”都不能直接等价为药物成功。

### 51. 硅谷对中国 AI 的最大误读，是把结果过度归因于政府支持

孟醒谨慎地说，他不能代表整个美国生态，但他经常遇到一种解释：把中国模型进步主要归因于政府资金、算力或政策支持。

他的反驳是，这种叙事低估了研究者、工程师和创业者在资源受限条件下的具体工作。政策和资源当然影响产业，但不能替代对个人能力、组织机制和技术方法的分析。

### 52. 理解中国 AI，既不要神化约束，也不要抹去行动者

“制裁逼出创新”与“全部依靠支持”是两种镜像式简化。前者把困难浪漫化，后者把人才和执行抹掉。

更有解释力的框架是：外部约束改变搜索空间，资本与政策决定资源边界，创始人决定组织目标，研究者和工程师决定这些条件最终变成失败还是创新。

## 中美 AI 生态差异：六个比“算力差距”更重要的变量

### 1. 人才市场：高流动促进扩散，低流动保存组织性格

美国前沿实验室之间的频繁流动，让新方法、训练经验和管理方式快速传播。中国实验室更稳定的核心团队，则让创始人意志和内部方法更容易长期保存。

评估影响时应同时看两种速度：知识在行业中的扩散速度，以及知识在单一组织中的积累速度。

### 2. 算力约束：决定搜索哪些问题，不直接决定创新质量

资源充足的团队更容易扩大已验证路线，资源受限的团队更有动力优化通信、内存、稀疏化和 Serving。两者探索的是不同问题空间。

但约束只有与人才密度、组织目标和实验纪律结合，才形成效率优势。缺资源本身没有技术红利。

### 3. 资本结构：决定是否有权选择“暂时落后”

依赖融资的模型创业公司，需要持续证明模型和用户增长；内部资金充足的大厂或拥有其他现金来源的团队，可以把短期领先让给别人。

长期主义不是态度测试，而是一项资产负债表能力。没有足够 runway，组织很难把它执行成技术策略。

### 4. 创始人作用：不只是定战略，还在定义研究品味

前沿模型的大量选择无法由客观公式决定：买什么数据、追什么 benchmark、是否扩大视频训练、是否开放权重、何时重做架构，都带有负责人判断。

创始人的作用通过人才、预算和评价标准进入模型。研究组织因此比成熟软件公司更难完全职业经理人化。

### 5. 产品与分发：决定真实数据能否回来

美国前沿实验室在模型和 Coding 工具上占据强入口，中国大厂则在短视频、消费内容和本地应用上拥有独特分发。谁更强取决于任务，不存在一张统一分发表。

产品入口的真正价值，是把用户行动、修正和结果转成训练与评测信号。如果数据不能回流，再大用户量也只是流量，不是模型资产。

### 6. 外部叙事：会反向影响研究注意力

如果美国研究者把中国模型主要理解为蒸馏或政策产物，他们可能忽略其中可学习的架构和系统方法；如果中国团队把所有进步解释成约束下的天才，也会低估算力、工具链和全球人才市场的真实差距。

叙事不是舆论附属品。它决定组织愿意研究哪些竞争者、复制哪些方法、忽略哪些风险。

## 开放权重如何改变模型经济学

### 从“模型替代”转向“角色路由”

未来系统更可能采用多模型协作，而不是只选择一个供应商：

| 角色 | 适合的模型 | 选择依据 |
| --- | --- | --- |
| 大量执行 | 成本较低、可部署的开放模型 | token 单价、吞吐、可控性、数据边界 |
| 高难判断 | 最强闭源或专用模型 | 任务成功率、置信度、复杂推理能力 |
| 审阅与验证 | 与执行模型错误相关性较低的第二模型 | 能否发现错误，而非平均能力最高 |
| 垂直步骤 | 用专有数据后训练的模型 | 局部任务表现、稳定格式、合规要求 |
| 多模态生成 | 视频、图像或语音专用模型 | 质量、延迟、版权、单位成品成本 |

这会把模型公司的份额拆成至少四个维度：默认入口、总 token、收入和高价值决策节点。开放模型可能赢得大量执行 token，闭源模型仍控制昂贵的关键步骤，两者可以同时增长。

### 三本不同的账

1. **token 量账：** 系统总共调用多少输入、输出、缓存和多模态 token。
2. **收入账：** 不同模型实际价格、渠道分成和折扣后产生多少收入。
3. **任务账：** 完成一项可交付工作用了多少轮、多少重试、多少人工检查，以及最终值多少钱。

只看第一本账，会把便宜小模型和昂贵推理模型视为相同单位；只看第二本账，会忽略降价带来的使用扩张；只有第三本账能连接用户价值，但也最难测量。

### 对前沿实验室的含义

- 能力领先仍然重要，但领先需要落到用户可感知的高难任务。
- 普通任务感知同质化后，品牌、产品、延迟和默认分发变得更重要。
- 开放模型压低执行成本，会迫使闭源模型证明其高价 token 的边际价值。
- 研究团队需要同时研究竞争方法和商业迁移，避免只看 benchmark。
- API 收入可能受到路由和替代影响，订阅、工作流和企业入口因此更关键。

## 从静态数据到环境数据：下一代模型公司的供给链

### 数据演进

| 数据形态 | 典型内容 | 主要作用 | 主要局限 |
| --- | --- | --- | --- |
| 互联网静态数据 | 网页、书籍、代码、论文 | 预训练知识与语言能力 | 高质量公开数据趋于稀缺，缺少任务反馈 |
| 人类专家数据 | 演示、评分、纠错、偏好 | 教授专业标准与行为 | 贵、慢、覆盖有限，质量验收困难 |
| 合成数据 | 模型生成的问答、轨迹、难题 | 扩大规模、定向补齐能力 | 继承教师偏差，容易形成同质化 |
| 真实用户轨迹 | 应用中的操作、修改、失败、完成结果 | 还原真实任务分布 | 隐私、权限、噪声和归因复杂 |
| 可执行环境 | SaaS 沙盒、代码仓库、模拟经营、实验平台 | 支持 RL、长程 Agent 和可验证评测 | 构建与维护成本高，线上线下差异大 |
| 物理与科学环境 | 机器人、商店、湿实验、临床流程 | 提供真实世界反馈 | 不可逆、昂贵、低频，安全和伦理要求高 |

### 环境的三层难度

1. **静态可重置：** 每次实验从同一状态开始，奖励稳定，例如 kernel 优化和代码测试。
2. **部分可观测：** Agent 只能逐步发现目标和规则，例如企业协作与组织偏好。
3. **动态不可逆：** 行动会改变市场、用户和物理世界，历史无法完全重放，例如交易、社交运营和真实经营。

难度提高后，benchmark 不再只是题目集，而是一套状态机、工具、其他参与者和评分规则。数据公司的研发重心也会从招募标注员，迁移到软件工程、领域建模与评测治理。

### Neo Lab 的闭环

`高频应用 → 专有任务轨迹 → 真实失败分布 → 垂直 eval / 环境 → 后训练专用模型 → 更低成本与更好体验 → 更多应用使用`

这条闭环成立需要五个条件：

1. 应用确实拥有高频且高价值的任务，而不只是流量。
2. 用户允许数据在明确边界内用于改进系统。
3. 结果可以被验证，或至少能从用户修正中提取可靠信号。
4. 专用模型的收益高于持续更换通用模型和调整 Harness。
5. 模型、产品与数据团队共享同一套 eval，避免各自优化不同目标。

## 数据公司：高速增长背后的两条路线

### 路线一：专家与项目交付

这类公司以招募专家、组织标注、质量控制和客户关系为核心，通常按人数、工时或项目收费。它能够快速承接前沿实验室不断变化的需求，也容易形成大额收入。

风险在于收入与人头高度相关，客户议价能力强，知识可能停留在项目团队。若不能把质检、招募、任务设计和领域知识产品化，规模越大，管理复杂度越高。

### 路线二：Benchmark、环境与研究产品

研究者型创业公司会提前判断前沿实验室需要什么任务，开发 benchmark、Agent 环境、工具和相应训练数据。一个复杂 DevOps 环境可能需要重建云控制面、权限和故障状态，价值远高于普通问答集。

这条路线的核心资产是研究品味和软件复用。风险则是 benchmark 与训练数据之间的利益冲突，以及客户需求变化后环境迅速过时。

### 判断一家数据公司质量的八个问题

1. 它卖的是人时、数据条数、环境、评测结果，还是模型能力增益？
2. 数据公司能否解释目标能力和失败分布，而不只是按规格交付？
3. 质量验收由谁定义，是否有隐藏测试集和跨版本回归？
4. 环境能否稳定重置，还是只能做一次性演示？
5. benchmark 制作者是否同时出售针对性训练数据，如何隔离利益冲突？
6. 专家数据是否真的需要该领域专家，还是把高学历当作质量代理？
7. 项目经验能否沉淀为工具、人才网络和可复用环境？
8. 模型提升能否迁移到未见任务，而不只是目标榜单？

## AI for Science：最容易被混在一起的三条路线

| 路线 | 系统做什么 | 当前最可行价值 | 核心瓶颈 | 合理验证单位 |
| --- | --- | --- | --- | --- |
| 科研助理 Agent | 检索论文、整理证据、写代码、分析数据 | 提高研究者日常效率 | 工具可靠性、引用、长链错误 | 节省时间、复现率、错误率 |
| 自动科学家 | 提出假设、设计实验、控制设备、解释结果 | 在限定环境内自动跑研究循环 | 湿实验连接、反馈速度、科学新颖性 | 可复现实验与同行认可 |
| 科学基础模型 | 预测或生成蛋白、细胞、材料和物理结构 | 缩小实验搜索空间、生成候选 | 数据稀缺、多尺度表示、最终 verifier | 实验命中率、开发周期、临床或产业结果 |

### 为什么 AI for Science 不能沿用 Coding Agent 的乐观外推

Coding 的状态、工具和 verifier 大多在线，失败可以低成本重跑；科学实验常常需要真实设备、材料和人类操作。一次失败可能耗费数天或数月，结果还可能受实验条件和测量噪声影响。

因此，AI for Science 的规模化不只需要更聪明的模型，还需要自动化实验室、标准协议、数据基础设施和分层 verifier。没有这些中间层，Agent 只能把研究文档做快，无法持续改进真实世界结果。

### 评估 AI for Science 公司时应追问

- 模型优化的是论文指标、体外实验、动物实验，还是最终临床结果？
- 从模型提出候选到获得真实反馈，需要多久、多少钱、多少人工步骤？
- 中间 verifier 与最终结果的相关性有多强，是否经过历史验证？
- 私有实验数据是否足以支持下一轮模型，还是每个项目都从零开始？
- 自动化平台能否产生标准化数据，还是实验流程高度依赖个人经验？
- 模型减少的是搜索空间、实验次数、研究人力，还是只提高了报告生成速度？

## 反共识判断与可复用金句

以下为对节目观点的中文压缩和意译，不是逐字引文。

1. **中国开放模型真正意外的不是拿到开放权重第一，而是开始逼近全球闭源前沿。**
2. **算力稀缺不会自动产生奇迹，稀缺加上世界级人才和明确目标才可能产生效率创新。**
3. **训练规模大十倍，不代表所有好方法都会先被你发现。**
4. **小团队的核心收益不是省工资，而是少丢上下文。**
5. **直接蒸馏最危险的结果，可能是让研发团队对自己产生错误满意。**
6. **只有不依赖下一轮融资的公司，才真正有资格公开选择落后几年。**
7. **开放模型对产业的影响，应用开发者可能比前沿研究者更早感知。**
8. **总 token 不降，模型公司的收入仍可能下降，因为昂贵 token 正被便宜 token 替换。**
9. **Coding Agent 能整夜工作，不只是因为模型会写代码，而是代码有可执行 verifier。**
10. **白领 Agent 的吞吐上限由人的反馈频率决定，所以延迟本身就是市场规模变量。**
11. **下一代 Neo Lab 不是先训练模型再找用户，而是先拥有应用和轨迹，再决定训练什么模型。**
12. **真正稀缺的数据不是下一批网页，而是模型在真实工作环境中失败和被纠正的过程。**
13. **未来的数据供应商可能同时卖考试和提分材料，这正是 benchmark 必须被审计的原因。**
14. **AI scientist 的 demo 不难，难的是做出科学共同体承认的新知识。**
15. **药物模型的最终 verifier 不是结合分数，而是多年后它能否安全地治病。**
16. **解释中国 AI 时，过度归因于政府与过度神化约束，都在抹去真正做事的人。**

## 给投资、产品与模型团队的决策框架

### 对投资人

不要只问“这家公司有没有自己的模型”，而要问：

- 它是否拥有其他实验室无法合法、稳定获得的任务轨迹？
- 自训模型是为了降低成本、提高能力，还是为了融资叙事？
- 模型优势能否在隐藏 eval 和真实客户结果中维持？
- 环境、数据和模型是否形成复利，还是每个客户都重新做项目？
- 公司能否承受基模更新、价格下降和开放模型迁移？
- AI for Science 的中间指标与最终产业结果相距多远？

### 对应用公司

自训模型之前，先完成四件事：

1. 把真实任务、用户修正和失败案例沉淀为 eval。
2. 计算整项任务成本，而不是比较公开 token 单价。
3. 用路由测试开放模型、闭源模型和专用模型的角色组合。
4. 明确数据授权、隐私和可回流边界。

只有当调用量、任务稳定性和局部数据优势都足够大时，后训练或自建模型才可能优于持续改进 Harness。

### 对模型公司

- 把竞争扫描从排行榜扩展到开发者迁移、模型路由和客户价格敏感度。
- 用真实办公、SaaS 和多模态任务补足研究者经验偏置。
- 将 Serving 速度作为人机协作能力的一部分，不只作为 Infra 指标。
- 明确区分独立研发增益、合成数据增益和外部教师增益，保护内部测量系统。
- 让开放报告能够被学习和复现，技术影响力会反过来吸引人才与生态。

### 对数据与评测公司

- 从“交付多少条”转向“解决哪种失败分布”。
- 环境必须有版本、重置、权限、状态和奖励规范。
- benchmark 与训练数据业务之间建立制度隔离和披露。
- 用未见任务、跨模型和线上结果检验迁移，而不是只展示榜单提升。
- 把专家招募、质检、环境开发和研究判断沉淀为可复用系统。

## 观点、事实与证据边界

### 可以由公开一手材料校准的内容

- 孟醒为五源资本合伙人。
- Kimi K3 为 2.8T 参数开放权重模型，采用 KDA、Attention Residuals、MoE 等技术，并面向 Coding、知识工作和长上下文任务。
- Seedance 2.0 是字节 Seed 发布的多模态音视频生成模型。
- Andon Labs 的 Vending-Bench 用长期经营模拟自动售货机测试 Agent 的一致性和决策能力。
- Mercor 在其[研究页面](https://www.mercor.com/research/)将 benchmark、evaluation environment 和专家数据列为前沿模型数据业务组成部分。

### 只能视为嘉宾观察或行业渠道信息的内容

- Moonshot、DeepSeek 等公司的具体团队人数、加班强度、内部人才授权方式和文化评价。
- 美国前沿实验室研究者对中国模型的关注度。
- Agent 公司迁移 K3 后对 Anthropic 等公司收入造成的具体影响。
- 某月 token 总量增长停滞、数据公司收入激增、单个视频应用收入跃升等商业数字。
- Seedance 训练使用的 GPU 数量、内部资源分配和具体负责人决策。
- 数据环境的项目报价，以及不同数据公司收入和增长速度。

### 需要特别避免的错误外推

1. 不能从“开放模型被采用”推出闭源实验室失去技术领先。
2. 不能从“直接蒸馏有效”推断某一家具体公司实施过未经授权的能力提取。
3. 不能从“团队年轻、工作投入高”推出模型成功必然来自工时。
4. 不能从 K3 一次发布推断 Moonshot 的长期商业模式已经成立。
5. 不能从 Seedance 的产品热度推断全部普通消费者已经形成高付费。
6. 不能从 benchmark 提升推断真实工作或科学发现能力同步提高。
7. 不能从中间生物学指标推断药物临床成功率。
8. 不能把政府支持、出口限制、人才努力或企业文化中的任何单一因素，当作中国 AI 进步的完整解释。

## 最终结论

这期访谈提供的不是一张静态的中美 AI 排名，而是一套理解产业变化的动态框架。

中国前沿实验室的进步，来自人才、创始人、资本结构和资源约束的特定组合；美国前沿生态的优势，来自更强算力、人才市场、工具链和商业入口。开放权重正在降低应用公司切换模型的成本，也把竞争从“谁有最强模型”推进到“谁能用最合适的模型完成整项任务”。

再往下看，真正稀缺的资产开始从互联网文本迁移到真实工作环境、用户轨迹和可验证反馈。应用公司可能先成为数据公司，再成为模型公司；数据公司可能从人力供应商变成环境开发者；AI for Science 则提醒行业，所有闭环最终都受制于 verifier 的速度和可信度。

如果只保留一个判断，可以是这一句：**AI 竞争的下一阶段，不是谁单独拥有更多智能，而是谁能把组织、模型、环境、反馈与分发连成更快、更可靠的学习循环。**
